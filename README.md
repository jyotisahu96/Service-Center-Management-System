
# Service Center Management System

A Django-based web application to manage daily operations of a service center.

## Features
- Customer Management
- Device Management
- Technician Management
- Service Request Management
- Billing and Invoice Management
- Payment Management
- Dashboard
- User Authentication
- Role-Based Access Control

## Technologies Used
- Python
- Django
- HTML
- CSS
- Bootstrap
- SQLite

## Project Structure
- service/ - Django application
- Servicehub/ - Project configuration
- template/ - HTML templates
- manage.py - Django management file

## Installation

1. Clone the repository:
   `git clone https://github.com/jyotisahu96/Service-Center-Management-System.git`

2. Install dependencies:
   `pip install -r requirements.txt`

3. Run migrations:
   `python manage.py migrate`

4. Start the server:
   `python manage.py runserver`

5. Open http://127.0.0.1:8000/ in your browser.

## Project Objective
To simplify service center operations by managing customers, devices, technicians, service requests, billing and payments in one application.
